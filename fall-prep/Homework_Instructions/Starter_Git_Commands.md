# Basic Git Commands

```bash
git init
```

Start Git in a folder.

```bash
git clone <url>
```

Download a GitHub project.

```bash
git status
```

See what changed.

```bash
git add <file>
```

Add a specific file to be saved.

```bash
git commit -m "message"
```

Save your changes.

```bash
git push
```

Upload your changes to GitHub.

```bash
git pull
```

Download the latest changes from GitHub.

```bash
git branch
```

See your branches.

```bash
git switch <branch>
```

Switch to a branch.

```bash
git log
```

See previous commits.

# Most Common

```bash
git add <file>
```
